# RifaPro Selenium

Proyecto desarrollado en React y Vite con pruebas automatizadas utilizando Selenium WebDriver.

## Tecnologías

- React
- Vite
- JavaScript
- Selenium WebDriver
- Mocha
- Chai

## Funcionalidades

- Inicio de sesión
- Gestión de Rifas (CRUD)
- Compra de boletos
- Automatización con Selenium
